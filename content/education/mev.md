# MEV (Maximal Extractable Value)

MEV is value extractable by controlling transaction inclusion, exclusion, or ordering — e.g. sandwiching DEX trades, liquidations, or arbitrage.

## Why researchers care
- User trade execution quality on public mempools
- Validator / builder / relay market structure
- Protocol design that minimizes harmful extraction

## Practical notes
1. Prefer documented routing / private orderflow options when researching execution — still verify.
2. Label builder/relay claims as ANALYSIS until you cite primary dashboards with timestamps.
3. Never invent “live” sandwich loss numbers — pull from labelled market/explorer sources or mark unavailable.

## Warnings
- MEV bots and “protection” UIs can be phishing. Verify domains.
- Paying for priority does not remove smart-contract risk.
