# Blockchain basics

A blockchain is a shared ledger updated by consensus rules.

## Building blocks
- **Blocks** batch transactions; **hashes** link history.
- **Consensus** (PoW/PoS/etc.) defines who may append.
- **Finality** differs by chain — “confirmed” is not universal.

## Diligence tips
- Read official docs for finality and bridge risk.
- Treat explorer data as facts; narratives as speculation.
- DEMO tables in MCCC are practice — never live chain state.
