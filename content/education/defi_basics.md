# DeFi basics

Decentralized finance rebuilds lending, trading, and yield via smart contracts instead of (or alongside) traditional intermediaries.

## Building blocks
- AMMs / DEX liquidity pools
- Lending markets and collateral factors
- Stablecoins and peg mechanisms
- Oracles for prices and other inputs
- Governance tokens (influence ≠ intrinsic value)

## Core risks
- Smart contract bugs / economic exploits
- Oracle manipulation
- Liquidity and depeg events
- Governance capture / hostile upgrades
- Approval / allowance drainers

## Research workflow
1. Official docs + audited contracts (date-stamp claims)
2. Track protocols in Project Tracker with stages and sources
3. Separate DEMO paper PnL from anything you treat as live
4. Revoke unused approvals; never share seeds

## Warnings
- High APY without primary sources is SPECULATION.
- Partner/referral links do not mean a protocol is safer.

> Not financial advice. Education only. Never treat DEMO PnL as live.
