# AI agents and crypto

AI agents can help summarize docs, structure notes, and draft checklists. They must **not** hold custody of funds or secrets.

## Safe uses inside MCCC
- Research checklists with FACT / DATA / ANALYSIS / SPECULATION labels
- Structuring notes linked to Project Tracker
- Answering workflow questions via rule-based or optional LLM providers

## Hard rules
1. Never paste seed phrases, private keys, or exchange 2FA into prompts
2. Never let an agent “sign” or broadcast with your keys
3. Never invent live prices — use Market APIs and respect LIVE vs DEMO
4. Treat agent output as draft research, not advice

## Warnings
- “AI trading bot” downloads and seed-sharing “setup wizards” are common scams.
- Autocomplete can hallucinate contract addresses — verify on explorers.

> Not financial advice. Education only. MCCC refuses credential-like input.
