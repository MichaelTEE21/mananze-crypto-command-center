# Wallets

A wallet manages keys that control addresses — it does not “store coins” like a purse.

## Types (high level)
- **Hot** software wallets — convenient, higher malware risk.
- **Hardware** — keys stay offline device; still verify addresses on-device.
- **Custodial** (CEX) — platform holds keys; you hold an account claim.

## MCCC rule
Only track **public addresses**. Never paste seeds or private keys into MCCC or random sites.
